# 账期对照台
纯静态服务项目现金规划：确认日/结算日、四类事项、逐日应收应付桥接与回款延迟对照。所有金额以整数分计算。

`node build.cjs` 构建单文件index.html；`node --test tests/core.test.cjs` 核心检查；静态HTTP服务器即可运行。

收入、费用按用户确认日计入简化收支差额，设备付款和注资不计该差额。现金按真实输入收付日净额累计。每天核对：现金=期初+确认差额−应收+应付−设备付款+注资。负现金表示缺口，补足按钮只改变期初假设。

模型不处理预收预付、分次结算、税费、折旧、利息、库存、借款偿还；初始往来为零。不是完整财务报表、投资建议或客户回款预测。默认数据是教学假设。

有效条件本机保存，备份导入先校验再替换。导出CSV全观察日（含0），MD全部事项、PNG摘要、JSON完整输入。无后台、外部调用、凭证或追踪代码。
